# ReceiptKeeper AI Models

Model files for the [ReceiptKeeper](https://github.com/macfather1980-tech/receiptkeeper) app.

## Files

| File | Size | Description |
|------|------|-------------|
| `gemma3-1b-it-int4.litertlm` | ~529 MB | Gemma 3 1B, INT4 quantized, LiteRT-LM format (text-only path) |
| `FastVLM-0.5B.litertlm` | ~900 MB | FastVLM 0.5B, INT8 quantized, LiteRT-LM format (vision-language, reads receipt photos directly, no OCR needed) |
